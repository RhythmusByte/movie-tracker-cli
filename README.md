# Movie Tracker CLI

> 🚧 UNDER DEVELOPMENT
> This project is still in active development and may change frequently.

A lightweight CLI application powered by the TMDB API to track movies and TV series, manage watchlists, and discover trending content directly from the terminal.

> [!NOTE]
> **This is a GitHub mirror.** The primary repository is hosted on Codeberg.
> All development, pull requests, issues, and releases happen there.
> 👉 [RhythmusByte/movie-tracker-cli on Codeberg](https://codeberg.org/RhythmusByte/movie-tracker-cli)

## Features

- Track movies and TV series
- Manage watchlists
- Discover trending content
- Simple terminal interface

## Tech Stack

- Python
- TMDB API
