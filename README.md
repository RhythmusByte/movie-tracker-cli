# Movie Tracker CLI

> 🚧 UNDER DEVELOPMENT  
> This project is still in active development and may change frequently.

A lightweight CLI application powered by the TMDB API to track movies and TV series, manage watchlists, and discover trending content directly from the terminal.

## Features

- Track movies and TV series
- Manage watchlists
- Discover trending content
- Simple terminal interface

## Tech Stack

- Python
- TMDB API
