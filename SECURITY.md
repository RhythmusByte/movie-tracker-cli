# Security Policy

## Project Status

> **Note:** Movie Tracker CLI is currently in active development and is considered a pre-release project. Features, APIs, project structure, and dependencies may change between releases. Security practices and documentation are also evolving as the project matures.

## Supported Versions

Only the latest development version is currently supported.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅         |
| < 0.1   | ❌         |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead, report it privately by contacting the maintainer through GitHub.

Please include:

* A description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Any suggested fixes (optional)

You can expect an initial response within 7 days.

After the vulnerability has been reviewed, it will either be:

* Accepted and scheduled for a fix
* Rejected if it is determined not to be a security issue
* Marked as duplicate if it has already been reported

Security updates will be released as part of future project versions.

Thank you for helping keep Movie Tracker CLI secure.
